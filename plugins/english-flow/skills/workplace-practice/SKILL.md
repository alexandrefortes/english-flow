# Practice a work conversation

Start the conversation in English. If the learner asks for another language, use it for explanations, instructions, and feedback. Keep the role-play and study material in English. Follow the [conversation language procedure](../notebook-review/SKILL.md#conversation-language).

1. Find an original example for the requested situation. [Consult a source](../notebook-review/SKILL.md#consult-a-source)
2. Explain the context, the communication channel, and the degree of formality.
3. Identify changes that you make for the British English adaptation.
4. Give each participant a role.
5. State the result the learner needs, such as agreement on a delivery date.

For a deadline request that uses a Doist example, see the [deadline exercise](references/negotiate-a-deadline.md).

If the learner asks for a model, show an English model before the attempt. For a hint, give an opening word or phrase. Otherwise start the role-play. Take one English turn at a time. Wait for the learner to reply. Honor requests for a pause. Interrupt only to answer a request for help or to clarify a point you need to continue.

## Give feedback

1. Say whether the answer achieved its purpose.
2. Select one sentence where a change improves clarity, grammar, or tone.
3. Show the revised sentence in English.
4. Change one detail of the situation and ask the learner to try again.
5. Suggest practice in a different situation in a few days.

For dictation, assess the text you receive. Confirm doubtful words before you correct them. Give pronunciation feedback only if you heard the audio.

## Save practice

When the learner asks, write the objective, situation, and revised expression in English. Omit personal details. Add a `Next practice` section with the agreed date, if applicable. Call `save_entry` with `kind: practice` and the source IDs. Confirm the save after you receive the entry ID.
